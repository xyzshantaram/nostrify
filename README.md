# Nostrify

Bring your projects to life on Nostr. 🌱

Nostrify is a Nostr framework for web browsers and Deno. It's made up of simple modules that can be used independently, or swapped out with your own implementations.

Use it alongside nostr-tools, NDK, or your existing application. Nostrify can be gradually adopted and plays nice with others.

## Quick Start

### React Projects
Check out our examples:
- Complete web implementation in `packages/react/example`
- For new projects, use our template:

```bash
# Create a new React project with Nostrify
deno run -A create-nostr-app init my-nostr-app --template react

# Or add to existing React project
deno add @nostrify/react
```

The React implementation includes all the core Nostrify features plus web and mobile optimizations and UI components.
